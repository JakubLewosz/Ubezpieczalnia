# Kontrakt API MVP
Wszystkie URL z końcowym `/`, JSON, sesje, CSRF `X-CSRFToken` z ciasteczka csrftoken. Błędy 400 walidacja, 403 anonimowy/CSRF, 409 konflikt wersji `{detail: ...}`. Listy DRF `{count,next,previous,results}` page_size 20. Mutacje PATCH z `version`.
- GET `/api/auth/csrf/` zapewnia ciasteczko; POST `/api/auth/login/` {username,password}; POST logout; GET me: `{id,username,first_name,last_name,role}`. role ADMIN/EMPLOYEE.
- GET `/api/dashboard/`: `{clients_count,review_count,failed_count,expiring_count,review_documents: Document[],failed_documents: Document[],expiring_policies: Policy[]}`.
- `/api/clients/` GET ?search=&ordering=display_name|-created_at&archived=false|true|all&page=, POST; `/api/clients/{id}/` GET/PATCH. Client `{id,kind:person|organization,first_name,last_name,organization_name,display_name,pesel,nip,email,phone,address,note,archived,version,created_at,duplicate_warnings:string[]}`. GET `/api/clients/{id}/history/` event array `{id,action,actor_name,created_at,object_type,object_id}`. Documents and policies lists filtered by client.
- `/api/policies/` GET ?client=&expires_in=7|30|60&archived=false|true|all&search=, POST; `/api/policies/{id}/` GET/PATCH. Policy `{id,insurer,number,insurance_type,start_date,end_date,premium:string|null,currency,subject,archived,version,participants:[{client:number,role:policyholder|insured,client_name:string}],document_ids:number[],coverage_status:upcoming|active|expired,duplicate_warnings:string[]}`.
- `/api/documents/` GET ?client=&search=; POST multipart `{client,policy?(id),category,file}`. Document `{id,client,client_name,policy,original_name,mime_type,size,checksum,category,page_count,created_at,author_name,duplicate_warnings:string[],latest_job:Job|null,review_status:pending|draft|approved|unsupported|attachment}`. Root creates documents.Document with fields `file` private FileField (file.path), `page_count`, etc. GET `/api/documents/{id}/`, GET `original/` authenticated attachment; GET `pages/{page}/` authenticated PNG (page >=1, extraction stores at MEDIA_ROOT/previews/{document_id}/{page}.png).
- Extraction owns `/api/documents/{id}/extract/` POST -> Job (202), and `/api/documents/{id}/review/` GET -> `{job:Job|null,engine_result:EngineResult|null,draft:Draft|null,revisions:RevisionSummary[]}`. Re-read never replaces existing draft/revisions; explicit POST `review/reset/` with `{version}` adopts latest result into new draft (409 stale).
- Job `{id,document,status:queued|running|succeeded|failed,error,created_at,started_at,finished_at}`. EngineResult `{id,profile,fields:Field[],warnings:string[],pages:[{number,method:text|ocr}]}`. Unsupported profile -> profile null, warnings includes `Brak profilu automatycznego odczytu` and succeeded technical job, no approvable draft.
- Field `{code,label,value:string|null,type:text|date|decimal|integer,unit:string,group:string,index:number,page:number|null,source:string,method:string,warnings:string[],manual:boolean,absent:boolean,updated_by?:string,updated_at?:string}`. Groups participants, vehicle, application, coverage, previous, payment. Engine fields source immutable. Corrected fields must clear source/page/method or mark method manual while retaining origin separately.
- Draft `{id,version,approved_version:number|null,fields:Field[],updated_at}`. PATCH `/api/documents/{id}/review/` `{version,fields:Field[]}` -> Draft, server validates field identity/type and records actual manual deltas. POST `/api/documents/{id}/approve/` `{version}` -> revision (201); 409 repeat approval same version. New draft edit after approval permitted, creates a new snapshot on subsequent approval.
- Revision summary `{id,number,author_name,created_at}`. GET `/api/revisions/{id}/` -> summary plus fields and document; GET `/api/revisions/{id}/export/` authenticated XLSX review_export_v0, never unapproved draft.
Common audit helper root provides `common.audit.record(user, action, object_type, object_id, client_id=None, metadata=None)`; metadata excludes document contents. Extraction should use direct same signature or its own safe helper fallback only during scaffold.
